Strapi Plans & API Usage Reference

Complete breakdown of CMS license plans, Strapi Cloud hosting tiers, API request counting, and overages — as of November 2026. For the Meridian project context: your Strapi is self-hosted Community Edition on Render — unlimited API calls, no meter.

1. Two separate things get priced

Strapi pricing has two independent axes. Mixing them up is the most common confusion:

CMS License = the software features you unlock (free Community, paid Growth / Enterprise). Applies the same whether you self-host or use Strapi Cloud.

Strapi Cloud = managed hosting — servers, DB, CDN, backups. Optional; you can self-host for free (what this project does on Render).

4. What counts as an "API request"

On Strapi Cloud, metering works like this:

Counted as API requestsNOT counted as API requests
  • Every request to the REST API (/api/*) — GET, POST, PUT, DELETE
  • Every request to the GraphQL API
  • All response types count — 200s, errors, empty results
  • File & media asset requests (/uploads/*) — those count toward asset bandwidth/storage instead
  • Admin panel traffic (/admin, /content-manager)

Quota resets monthly (even on annual plans). Hitting limits on paid plans triggers overage billing; projects are only suspended for unpaid invoices or plan violations.
